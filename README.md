# ITO – Partyspiel

Eine kleine, browserbasierte Umsetzung des Spiels aus der Spielbeschreibung.

## Starten

Einfach im Projektordner einen lokalen Webserver starten:

```bash
cd /Users/moreno/Documents/VScode/ito-spiel
python3 -m http.server 8000
```

Danach im Browser öffnen:

```text
http://localhost:8000
```

## Features

- 4–7 Spieler verwalten
- Themen und Skalierungen auswählen
- Geheime Zahlen zufällig verteilen
- Host-Reihenfolge per Drag & Drop sortieren
- Auflösung mit Fehlerpaaren anzeigen
- Spieleransicht mit Verstecken/Merk-Button

## Hinweis

Die App ist bewusst als leichtes Frontend umgesetzt, damit sie schnell gestartet und ausprobiert werden kann.
